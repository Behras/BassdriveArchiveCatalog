# Bassdrive Archive Catalog

Public metadata feed for the BassdriveTerminal Android app. It contains show
names, archive availability, episode counts, and broad drum and bass style
tags. It does not contain the Android source code or audio files.

## Data

- `data/shows-v1.json` contains show names, aliases, and style tags.
- `data/archive-index-v1.json` contains generated folder availability and
  episode counts.
- `data/archive-index-v1.json` is generated by the sync workflow and should
  not be edited manually.

The Android app reads the public files directly from this repository and
keeps the packaged catalog as a fallback.

## Curating A Show

Edit `data/shows-v1.json` on GitHub. For a reviewed entry, set `tagSource` to
`CURATED`; automatic updates preserve curated tags.

Allowed tags:

- `LIQUID_SOULFUL`
- `DEEP_ATMOSPHERIC`
- `JUNGLE_BREAKS`
- `TECH_DARK`
- `DANCEFLOOR_JUMP_UP`
- `FULL_SPECTRUM`
- `UNCLASSIFIED`

Shows can have multiple tags. Keep every real Bassdrive archive folder name
in `aliases` so renamed and duplicated folders remain grouped together.

## Automatic Updates

The `Sync archive catalog` GitHub Action runs daily at 04:17 UTC. It can also
be started manually from the repository's Actions tab.

The scanner compares archive folder timestamps, revisits changed folders,
counts playable MP3 files, records broken placeholders, and adds newly found
shows. On the first UTC day of each month it performs a full scan.

If the action cannot commit an update, open `Settings > Actions > General`
and set `Workflow permissions` to `Read and write permissions`.
